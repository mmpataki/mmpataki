### Hi, I'm Madhusoodan 👋

Engineer at Salesforce (previously Informatica), based in Bengaluru. I debug large distributed data platforms in production and build the backend tools that make that faster. I like measuring things before optimizing them.

**Things I've built**

- [inferj](https://github.com/mmpataki/inferj): GPT-2 inference in a single Java file, no dependencies, with its own tensor library and KV cache
- [car](https://github.com/mmpataki/car): distributed log processing and analysis; a fork runs in production with ~1K users
- [sdfs](https://github.com/mmpataki/sdfs): small distributed filesystem and job scheduler, run on 70 nodes
- [metmon](https://github.com/mmpataki/metmon): metrics monitor with a Hadoop metrics sink for HBase, HDFS and YARN
- [active-trace-ids](https://github.com/mmpataki/active-trace-ids): trace IDs that carry flags, so debug logging can be switched on for a single request
- [tensor.benchmark](https://github.com/mmpataki/tensor.benchmark): benchmarks, perf data and tools behind my blog series "Taking JVM on a performance ride"
